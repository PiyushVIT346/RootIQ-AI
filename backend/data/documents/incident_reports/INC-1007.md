# INC-1007: PostgreSQL Disk Pressure

Date: 2026-11-02
Severity: SEV-1
Status: Resolved
Infrastructure: pg-primary-01

## Description
Database disk utilization reached 97%, causing
write failures and increased query latency.

## Evidence
- WAL archive backlog increased.
- Temporary table size increased significantly.
- Free disk space fell below 8GB.

## Root Cause
A maintenance query created large intermediate
temporary tables without execution safeguards.
WAL cleanup was delayed by an archive destination issue.

## Resolution
Stopped the maintenance job, restored WAL archival,
and removed validated temporary artifacts.

## Prevention
- Disk growth alerts.
- Query resource limits.
- WAL archive monitoring.
- Maintenance job dry runs.
