# INC-1003: Authentication Certificate Expiry

Date: 2026-10-18
Severity: SEV-1
Status: Resolved
Service: auth-service
Infrastructure: ingress-gateway

## Description
Users experienced authentication failures because
the TLS certificate had expired.

## Impact
Login success rate decreased to 72% for 26 minutes.

## Evidence
- Gateway logs showed certificate expired.
- Certificate expiration date was 2026-10-18.
- No automated expiry alert existed.

## Root Cause
Certificate renewal was manual and the assigned
owner was inactive.

## Resolution
Renewed and deployed the certificate.
Validated the certificate chain.

## Prevention
- Automated certificate renewal.
- Alerts at 30, 14, and 7 days.
- Primary and backup certificate owners.
