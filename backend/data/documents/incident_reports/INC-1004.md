# INC-1004: Kafka Order Queue Backlog

Date: 2026-10-21
Severity: SEV-2
Status: Resolved
Service: order-service
Infrastructure: kafka-orders, pg-primary-01

## Description
Kafka consumer lag increased to 185000 messages.

Order status updates were delayed by up to 17 minutes.

## Evidence
- Consumer throughput decreased from 4200 to 900 messages/min.
- Database write latency reached 1.4 seconds.
- Transaction timeouts occurred.
- Consumer group rebalances increased.

## Root Cause
Large batch processing increased transaction duration.
Database contention caused transaction timeouts and
repeated Kafka consumer rebalances.

## Resolution
- Reduced batch size from 1000 to 200.
- Increased consumer replicas from 4 to 8.
- Monitored queue lag until recovery.

## Prevention
- Alert on consumer rebalance rate.
- Monitor database write latency.
- Load test consumer scaling.
