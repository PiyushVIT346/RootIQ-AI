# INC-1001: Checkout API Failure

Date: 2026-10-14
Severity: SEV-1
Status: Resolved
Service: checkout-api
Related Services: payment-api, pg-primary-01

## Description
Checkout API returned HTTP 503 errors because payment processing
requests were taking too long.

## Impact
- 2,840 checkout attempts failed or timed out.
- Checkout success rate decreased from 99.7% to 61.2%.
- Incident duration: 39 minutes.

## Timeline
10:02 UTC - Checkout 5xx alert triggered.
10:05 UTC - Platform SRE acknowledged.
10:11 UTC - Payment API latency reached 2.8 seconds.
10:16 UTC - Database connections reached 480/500.
10:24 UTC - Payment concurrency reduced.
10:33 UTC - Database connections decreased.
10:41 UTC - Service recovered.

## Evidence
- PostgreSQL connection saturation.
- Payment API connection acquisition timeout.
- Increased retry attempts.
- Elevated checkout response time.

## Root Cause
Aggressive payment API retries and excessive connection
pool concurrency exhausted PostgreSQL connections.

## Resolution
Reduced worker concurrency, capped database connections,
and reduced retry attempts.

## Prevention
- Implement exponential backoff.
- Configure service-level connection budgets.
- Monitor database pool wait time.
- Perform retry load testing.
