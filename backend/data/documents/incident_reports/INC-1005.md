# INC-1005: Inventory Cache Stampede

Date: 2026-10-25
Severity: SEV-2
Status: Resolved
Service: inventory-service
Infrastructure: redis-cache-01, pg-primary-01

## Description
Inventory API latency increased after popular Redis
cache keys expired simultaneously.

## Impact
Inventory lookup p95 latency increased from 90ms to 1600ms.
Checkout conversion dropped by 18% for 19 minutes.

## Evidence
- Redis hit ratio dropped from 96% to 21%.
- PostgreSQL read QPS increased 5.1 times.
- Repeated cache misses occurred.

## Root Cause
Synchronized cache expiration created a cache stampede.

## Resolution
Warmed frequently requested keys and enabled request locking.

## Prevention
- Add TTL jitter.
- Implement request coalescing.
- Add cache hit-ratio alerts.
- Implement stale-while-revalidate where appropriate.
