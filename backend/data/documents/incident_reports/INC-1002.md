# INC-1002: Payment API Latency

Date: 2026-10-14
Severity: SEV-2
Status: Resolved
Service: payment-api
Infrastructure: pg-primary-01

## Description
Payment API p95 latency increased from 240ms to 2800ms.

## Evidence
- Connection acquisition time reached 1.9 seconds.
- PostgreSQL connections reached 480/500.
- Retry count increased 6.4 times.
- Checkout API began returning HTTP 503.

## Root Cause
Database connection pool saturation caused by
aggressive application retries.

## Resolution
Reduced concurrency and retry attempts.

## Relationship
This incident is linked to INC-1001.
Both incidents represent different symptoms of
the same database connection exhaustion event.

Related Postmortem: PM-1001
