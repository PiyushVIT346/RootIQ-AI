# PM-1005: Payment API Memory Leak

Related Incident: INC-1006

## Root Cause
New metrics middleware retained request and response
objects in an unbounded global map.

## Important Distinction
INC-1002 was caused by PostgreSQL connection exhaustion.
INC-1006 was caused by application memory leakage.

## Corrective Actions
- Deployment rolled back.
- Middleware disabled.
- Memory soak testing planned.
- Object lifecycle review planned.
