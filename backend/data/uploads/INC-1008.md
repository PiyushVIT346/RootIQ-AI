# INC-1008: Ingress Routing Regression

Date: 2026-11-06
Severity: SEV-1
Status: Resolved
Infrastructure: ingress-gateway
Services: checkout-api, auth-service

## Description
A gateway configuration rollout caused HTTP 404
and 502 responses for some API requests.

## Evidence
Gateway logs showed requests being routed to
an outdated backend pool.

## Root Cause
A route matcher precedence change shadowed the
intended /api/v2 routing rule.

## Resolution
Rolled back gateway configuration and validated
routing using smoke tests.

## Prevention
- Configuration review.
- Staged rollout.
- Route-level synthetic tests.
- Automatic rollback on increased 5xx errors.
