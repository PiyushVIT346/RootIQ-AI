# PM-1003: Kafka Consumer Backlog

Related Incident: INC-1004

## Root Cause
Oversized Kafka consumer batches increased transaction
duration. Database contention caused transaction timeouts
and repeated consumer group rebalances.

## Corrective Actions
- Batch size reduced to 200.
- Consumer replicas increased to 8.
- Rebalance alerts planned.
- Database latency injection tests planned.

## Operational Lesson
Scaling consumers alone is insufficient if the
database is the downstream bottleneck.
