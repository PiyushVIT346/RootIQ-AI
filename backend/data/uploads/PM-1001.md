# PM-1001: Database Connection Exhaustion

Related Incidents: INC-1001, INC-1002
Infrastructure: pg-primary-01

## Root Cause Chain
Traffic increase
    -> Payment API retry amplification
    -> Increased concurrent database requests
    -> Connection pool saturation
    -> PostgreSQL connection exhaustion
    -> Payment API latency
    -> Checkout API HTTP 503

## Contributing Factors
- No service-level connection budgets.
- No retry jitter.
- Incomplete load testing.
- Missing connection wait-time alerts.

## Corrective Actions
Completed:
- Payment API pool capped at 80.
- Retry attempts reduced to 2.

Planned:
- Database connection budgets.
- Connection acquisition latency SLO.
- Database saturation chaos testing.

## Verification
Replay test at 1.8x normal traffic kept
active database connections below 310.
