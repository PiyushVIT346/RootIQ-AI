# INC-1006: Payment API Memory Leak

Date: 2026-10-28
Severity: SEV-2
Status: Resolved
Service: payment-api

## Description
Payment API memory usage increased continuously after
deployment pay-2026.10.28.3.

## Evidence
- Memory increased from 420MB to 1.9GB.
- Application instances restarted.
- Database connections remained normal.
- Heap profile showed retained response objects.

## Root Cause
A newly deployed metrics middleware retained request
and response objects in an unbounded global map.

## Resolution
Rolled back the deployment and disabled the middleware.

## Prevention
- Memory soak tests.
- Bounded cache implementation.
- Middleware lifecycle review.
- Memory growth-rate alerts.

Related Postmortem: PM-1005

Important:
This incident has a different root cause from INC-1002,
even though both involve payment-api.
